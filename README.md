# Bagath Singh — Product Design Portfolio

A responsive React portfolio built with Vite.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Project structure

- `src/App.jsx` — homepage, project navigation and theme toggle
- `src/CaseStudy.jsx` — individual case-study content
- `src/styles.css` — homepage styles, responsive layout and motion
- `src/case-study.css` — case-study page styles
- `vercel.json` — SPA route fallback for direct case-study URLs

The `portfolio-redesign` branch contains the redesign. The `main` branch has not been changed by this implementation.
